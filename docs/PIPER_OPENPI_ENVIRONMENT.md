# openpi 独立环境记录

本环境用于离线适配检查；不访问 CAN，也不代表机械臂可以自主运行。演示数据的反馈实体、
动作时间语义和夹爪执行映射尚未确认，当前数据保持 `training_ready=false`。

## 数据现状

`banana-direct-a06-002-diagnostic-portable-20hz-v2` 是包含 61 个重叠窗口的诊断副本；
20 Hz 是审计假设，不是已经确认的执行频率。这些窗口不是 61 条独立演示，也不是正式训练集。
已在独立 Python 3.11 环境中逐条完成离线读取检查，但这不验证真实运动或策略质量。
在上述 openpi 环境中使用该副本的第一个窗口，通过官方 `PadStatesAndActions` 和
`ResizeImages` 变换：状态变为 `32` 维，动作变为 `50×32`，三张图均为 `224×224×3`；
原七维数值保留并以零补齐。这只是格式检查，不是完整模型输入、训练或推理验证。

官方安装入口：[openpi 固定版本说明](https://github.com/Physical-Intelligence/openpi/blob/215abfb217dbac7d5f1273282331b9b1866c0479/README.md)。

## 已有演示的状态与目标对照

2026-11-09 对 `a06-002` 的 v2 诊断副本中 61 个窗口，比较每个观测状态和该窗口首个
动作目标。这些窗口只覆盖约 25.4 秒，且经过新鲜度与完整窗口筛选，不代表完整演示；
状态与目标按时间就近取样，最大源年龄分别约 4.96 ms 和 25.60 ms，并非完全同步。

六个关节的目标与反馈的样本相关系数约为 0.990～0.998；关节绝对差中位数约
0.0038～0.0199 rad。夹爪相关系数约 0.874，绝对差中位数约 1.5 mm，最大约 25.9 mm。
相关性与差值只能说明这些记录的数值关系：无法据此识别反馈来自主臂还是从臂，也不能区分
跟随延迟、采样或真实夹爪行为，不能据此判定故障或确认训练执行映射。后续应结合现场接线、
固件配置和官方协议确认身份与目标保持规则，保留原始数据，确认后再安排正式数据转换。
